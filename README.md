# 墨影书城 · 一页一画

有画面感的小说 App（前端工程）。**普通小说、画面互动小说、漫画、动漫视频**四种读法；创作者上传作品（漫画支持自选图片、互动小说带画面人物），管理员后台审核授权、推流量，收益经管理员审核后结算提现。所有封面、场景插画、漫画分镜、头像均由程序化 SVG 生成，全站无外部图片依赖。

## 功能

- **四类作品**：普通小说（章节连载，14 类题材）、画面互动小说（场景插画 + 画面人物 + 剧情分支 + 多结局）、漫画（分镜页面 + 对话气泡，支持创作者自选上传图片）、动漫视频（仅管理员上传 mp4/webm，浏览器 IndexedDB 存储）
- **分类书城**：按类型与题材筛选，编辑推荐（管理员推流量）、热门榜、新书上架、猜你喜欢
- **阅读器**：小说章节阅读、互动剧情引擎、漫画分镜阅读（自定义图片优先）、动漫视频播放；书币充值（可选充值方式，管理员可开关）、VIP 全免、章节订阅、打赏
- **书架 / 搜索 / 登录注册**：进度同步、最近阅读、账号体系；注册支持账号 / 手机号（短信验证码）/ 邮箱，登录支持账号密码与微信 / QQ 快捷登录
- **追更通知**：书架收藏角标（有未读新章节亮红标）
- **签到 / 每日任务**：每日签到 +10 币、今日阅读一章 +5 币，连续签到天数统计
- **排行榜**：热读榜 / 新书榜 / 打赏榜三榜实时聚合
- **账号安全**：修改密码（验证原密码）、找回密码（验证码重置）、提现二次验证（登录密码确认）+ 风控（单笔 ≤500 元、每日 ≤3 次）
- **读者隐私化**：隐私设置 5 项开关 + 清除阅读历史
- **意见反馈渠道**：读者提交建议 / Bug / 举报，管理员后台回复
- **客服站内信**：读者「联系客服」实时会话，管理员后台回复（未读角标）
- **创作者中心**：开通创作者需资质审核（附首部作品初步发布）；四类上传编辑器（章节 / 剧情节点 / 分镜页传图 / 动漫视频）、作品管理、收益中心、提现申请；上传作品需管理员审核上架
- **用户等级**：六级（见习书虫 → 传奇书灵），高等级优质作品更易被推荐流量
- **管理后台（安全码保护）**：安全码连错 5 次锁 10 分钟；数据概览、用户与等级（VIP 授权 / 等级调整 / 封禁 / 书币调整，全部审计）、资质审核、作品审核（通过/驳回/下架/隔离/推流量）、收益结算审核、提现审核（含渠道审核）、用户服务（反馈工单 + 客服信箱）、安全中心（查杀/防篡改/审计）、全站设置
- **收益保护流**：订阅/打赏 → 待结算单 → 管理员审核 → 可提现余额 → 绑定提现渠道（管理员审核） → 申请提现（冻结）→ 放款/驳回退回，全程流水 + 审计

## 安全体系

- **内容查杀**：全站文本扫描脚本注入 / javascript: / iframe / on* 事件劫持 / img onerror / eval / 存储探测 / DOM 直写 / svg onload / data: HTML 等危险载荷；发现即隔离作品
- **防篡改守护**：数据写入附加哈希签名 + shadow 备份；读取校验签名，不匹配自动恢复；每 30 秒自动巡检，跨标签页改写实时监控
- **入侵警告**：全站顶部横幅告警（数据篡改 / 病毒注入 / 暴力破解）
- **数据库护死**：签名失效且无有效备份的数据直接丢弃并记录日志
- 注：以上为前端演示级防护（localStorage + IndexedDB + 哈希签名），真实生产环境需服务端鉴权与数据库层防护

## 数据说明

- 纯前端实现：业务数据在浏览器 localStorage（命名空间 `moying-novel`，每键签名 + shadow 备份），首次访问自动写入种子数据
- 上传的漫画图片与动漫视频存 IndexedDB（`moying-novel-files`），不占 localStorage 容量
- 换浏览器 / 换设备数据不共享；API 层（`src/lib/api.ts`）以内存 + localStorage 模拟后端
- 付费模型：1 元 = 100 书币（可配置）；VIP 1800 币/月（可配置）；订阅分成 70%、打赏 100%、VIP 创作者分成 +10%
